# PineLab · dashboard

Veřejný přehled všech strategií PineLab (papírové signály + DEMO obchody na MT5). Žádné reálné peníze.

* Stránka: https://janik4321sdfa.github.io/pinelab-dashboard/
* Data: ledgery ze soukromého repozitáře (jen čtení), ceny zlata Yahoo GC=F 60m.
* Build: `build.py` (jen standardní knihovna) → `site/index.html`, každou hodinu a po každém obchodu.

Papír = výpočet z tržních cen podle zveřejněného signálu. Demo = skutečné filly na demo účtu (fiktivní peníze).
